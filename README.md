# Bank Prompt AI

Kumpulan prompt siap pakai untuk produksi konten (video dokumenter, Veo/Gemini, gambar).
Dikumpulkan dari Threads/sosmed dan prompt yang sudah terbukti dipakai sendiri.

## Isi

### Dokumenter Peta (Gemini Neon / Veo)
- [Animasi Peta 3D dari Google Maps (alur kerja + templat)](dokumenter-peta/animasi-peta-3d-maps-veo.md) — sumber: @buildfastwithai (Instagram)

### Templat
- [Templat Dokumenter Peta 60 detik](templat/dokumenter-peta-60s.md) — kerangka kosong, tinggal ganti tokoh/rute/naskah

## Cara pakai
1. Buka berkas prompt-nya, salin seluruh teks.
2. Tempel ke Gemini (mode video/Neon) atau Veo/Flow.
3. Untuk tokoh/rute lain, pakai templat dan isi bagian kurung siku.

## Catatan sumber
- Prompt bertanda "teks penuh" = teks aslinya utuh.
- Prompt bertanda "alur kerja + templat" = dirangkum dari postingan kreator (teks asli mereka dikunci di balik komentar/DM), strukturnya ditulis ulang sebagai templat yang bisa langsung dipakai.
